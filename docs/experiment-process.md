# 从第一版到第三版

本页按实际实验顺序记录设计、修改理由和结果。所有版本都没有使用梯度下降或样本拟合。第二、三版使用了开发测试反馈。

## 1. 先把一个接球策略写进网络

第一版使用 `400 → 794 ReLU → 3` 网络，输入为 MinAtar 原始四个对象通道。隐藏单元识别球和上一帧轨迹的局部组合；输出权重编码侧墙反弹后的预计落点。

球下降时预判，球上升时跟随当前横坐标。结构与权重先固定，再开始游戏测试。

种子 `0–999`，各 1,000 局，重复动作概率 0.1：

| 策略 | 平均得分 |
| --- | ---: |
| 预测落点网络 | 16.539 |
| 简单追球 | 8.366 |
| 随机操作 | 0.370 |
| 全零权重 | 0.507 |

这个版本能独立运行，但球反弹时，挡板经常位于场地另一侧，来不及追上。证据：[逐局结果](../experiments/v1/results/episodes.csv)、[固定第一局回放数据](../experiments/v1/results/replays.json)。

## 2. 提前考虑砖块，把预测贯穿上升阶段

第二轮仍保持相同网络大小。先尝试上升时回到中央，再加入沿飞行方向的砖块检测，最后把预测扩展到上方区域。

六个候选使用同一组开发种子 `2000–2127`，每个 128 局：

| 候选 | 主要变化 | 开发均分 |
| --- | --- | ---: |
| `center_old` | 中央等待，选择原横坐标接球 | 27.180 |
| `center_interval` | 接受两个可接球位置 | 56.734 |
| `brick_old` | 加入砖块碰撞预测 | 67.492 |
| `brick_interval` | 预测碰撞，同时接受接球区间 | 69.414 |
| `extended_old` | 将预测扩展到整个飞行阶段 | 276.391 |
| `extended_safe` | 最后一步接受接球区间 | 254.469 |

接受更宽的接球区间让部分候选存活更久，但也可能让球反复沿已清空的路线往返。存活时间增加不必然带来更多得分。

根据开发均分选定 `extended_old`，冻结后换用种子 `30000–30999`：新版 **255.997** 分，第一版同条件 **17.959** 分。此前未用过这些测试种子。证据：[选择记录](../experiments/v2/selection.json)、[比较](../experiments/v2/comparison.json)。

剩余问题是随机重复动作：模型请求停止，环境仍可能再向左或向右移动一步。接球前的这种偏移会导致漏球。

## 3. 扩大架构，直接写入记忆和随机控制规则

第三轮允许改变架构。新增 12 维内部记忆，用来保留上一帧挡板位置和推断出的竖直方向。记忆来自观察历史，没有读取模拟器隐藏变量。

根据预计接球时间、可接位置、当前挡板位置及上次移动方向，用有限时域动态规划计算控制表。计算使用已知转移规则，不使用游戏样本拟合。随后把控制表编译成固定神经网络权重。

开发集仍为 `2000–2127`，比较三个终端偏好系数：

| 系数 | 开发均分 |
| --- | ---: |
| 0.01 | 674.367 |
| 0.05 | 628.422 |
| 0.20 | 579.320 |

选择 0.01 后冻结模型，不再根据最终测试结果修改权重。[选择记录](../experiments/v3/selection.json)保留了全部候选。

## 4. 复跑公开基线，再做同协议比较

使用原研究仓库 `4d09ba6d6a7e891dd8063974dfe81b3d78e3494f` 的未修改 checkpoint。环境固定为 MinAtar 1.0.15，按原研究编码六通道观察，并从 softmax 采样动作。

原研究报告均分 517.411、标准误 7.417。预先指定的复跑接受条件为：均值差不超过三倍合并标准误。在种子 `100000–100999` 上复跑得到 **508.268**，通过该条件。这是公开模型的数值复跑，不是整项研究或 PPO 训练流程的完整复现。

之后，双方在新种子 `200000–200999` 上各运行 1,000 局：V3 **672.681**，公开模型 **512.860**。配对增益 95% bootstrap 区间为 **142.271–178.183** 分。[完整逐局数据](../experiments/v3/heldout-ours/episodes.csv)和[公开模型结果](../experiments/v3/heldout-reference/episodes.csv)均保留。

V3 更大、带记忆，并使用过开发反馈；原研究小网络为一次生成。这里比较的是相同游戏协议下的得分，不是同规模或同开发预算的效率。

## 5. 压力测试与未解决的问题

在种子 `300000–300199` 上，将重复动作概率提高到 0.25，各测 200 局：V3 **163.990**，公开模型 **75.005**。V3 的控制表仍按 0.1 构造，没有根据压力测试重新调整。

尚未完成的工作包括：同规模对照、参数压缩、其他游戏迁移，以及不提供完整规则源码时的构造实验。当前结果只覆盖 MinAtar Breakout。
